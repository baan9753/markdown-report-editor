# 마크다운 보고서 편집기

마크다운으로 보고서를 쓰고 사진을 붙여넣으면 오른쪽에서 완성된 문서를 바로 확인할 수 있습니다. PDF에 사진이 포함되므로 받는 사람에게는 PDF 한 파일만 보내면 됩니다.

**[브라우저에서 편집기 열기](https://baan9753.github.io/markdown-report-editor/md_to_pdf.html)**

오프라인에서도 쓸 수 있습니다. [편집기 HTML 파일](./md_to_pdf.html)을 다운로드한 뒤 브라우저에서 여세요. 글과 사진은 브라우저 안에서 처리합니다.

## 사진이 들어간 PDF 만들기

1. 왼쪽에 `# 현장 점검 보고서`를 입력하고, 다음 줄에 점검 내용을 적습니다.
2. 사진을 넣을 위치에서 `Ctrl+V` 또는 `⌘V`로 붙여넣습니다. **사진 첨부** 버튼을 누르거나 사진을 왼쪽 편집창에 끌어다 놓아도 됩니다.
3. 새 장에서 시작할 문장 앞에 커서를 놓고 **페이지 나누기**를 누릅니다. 미리보기의 점선이 PDF의 페이지 경계를 표시합니다.
4. **PDF 내보내기**를 누르고 인쇄 창에서 **PDF로 저장**을 선택합니다. 날짜와 웹 주소를 빼려면 인쇄 옵션에서 머리글과 바닥글을 끕니다.

## 저장하고 이어서 쓰기

창을 닫기 전에 **원본 저장**을 누르세요. 본문, 첨부한 사진, 선택한 색이 하나의 `.md` 파일에 저장됩니다. 다음에 **열기**로 파일을 선택하거나 편집기 창 어디에나 끌어다 놓으면 이어서 작성할 수 있습니다.

## 편집 도구

| 도구 | 동작 |
| --- | --- |
| 메인 컬러 | 제목과 소제목의 글자색, 큰 제목 아래 선 색을 바꿉니다. |
| 서브 컬러 | 링크, 인용문, 표 머리글의 색을 바꿉니다. |
| 이전 · 다음 | 글 입력, 사진 첨부, 페이지 나누기, 색 변경을 취소하거나 다시 적용합니다. `Ctrl+Z`와 `Ctrl+Shift+Z`도 사용할 수 있습니다. Mac에서는 `⌘Z`와 `⌘Shift+Z`를 사용하세요. |
| 스크롤 | 어느 쪽에서 스크롤해도 원본과 미리보기가 같은 문단을 따라갑니다. |
